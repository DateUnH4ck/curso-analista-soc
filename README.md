Cada episodio del curso en YouTube tiene aquí su carpeta, con los comandos,
las consultas, el reto del episodio y su solución.

Todo se practica sobre el mismo laboratorio: **[soc-lab](https://github.com/DateUnH4ck/soc-lab)**.
Móntalo antes de empezar.

## Temporadas

| Temporada | Módulos | Objetivo |
|---|---|---|
| [**T1 · Fundamentos para SOC**](T1-fundamentos/) | Lab, redes, Windows/Linux, Active Directory, operación SOC | Base y mentalidad de analista |
| **T2 · Analista N1** | Frameworks, logs, SIEM, phishing, CTI, informes | Trabajar de N1 |
| **T3 · Transición a N2** | Red, endpoint/EDR, triaje de malware, respuesta a incidentes | Investigar incidentes completos |
| **T4 · Analista N2** | Sigma, threat hunting, cloud, automatización, caso final | Nivel N2 |

## Cómo está organizado cada episodio

```
T1-fundamentos/
└── E01-que-es-un-soc/
    ├── README.md      ← resumen, comandos y enlaces del vídeo
    ├── reto.md        ← el reto del episodio
    └── solucion.md    ← la solución (¡inténtalo antes!)
```

## Series paralelas

- **Ataco y lo detecto**: ejecuto una técnica de ATT&CK en el lab y la cazo en el SIEM.
